Neural Bigram Model Visualizer

This shows the neural version of a bigram model. Instead of storing counts directly, we learn a vocab × vocab weight table. Each row is an embedding for one token, and that row directly becomes the logits for the next token.

Inference

At inference time there is no target and no loss. We only do: token → logits → softmax → sample next token.
